# Taskboard

Общий список задач: создание, просмотр, редактирование, удаление и фильтр по статусу. Данные хранятся в PostgreSQL.

**Стек:** Kotlin, Spring Boot, PostgreSQL, Flyway. Фронтенд — HTML, CSS и JavaScript.

## Запуск и проверка

Нужен запущенный Docker с Compose. Из папки проекта выполните:

```sh
docker compose up --build -d --wait
```

Откройте **[http://localhost:8080](http://localhost:8080)**. Создайте задачу, обновите страницу, измените задачу и удалите её — это проверка всех CRUD-операций.

[Проверка сервера и БД](http://localhost:8080/health/ready) должна вернуть `{"status":"UP"}`. Первый запуск скачивает зависимости и может занять несколько минут.

Остановка: `docker compose down`. Задачи сохраняются. В `compose.yaml` уже заданы учебные настройки; при необходимости их можно переопределить через `.env` по примеру `.env.example`.

## Архитектура

```text
Браузер → Controller → Service → Repository → PostgreSQL
```

Контроллер принимает HTTP-запросы, сервис выполняет операции с задачами, репозиторий содержит SQL. Модели — в `model`, входные данные — в `dto`. Модель и сервис не зависят от Spring и JDBC. Фронтенд отдаётся тем же приложением.

В IntelliJ IDEA откройте `pom.xml` с JDK 21. Автотесты: `mvn verify` — нужны Maven и работающий Docker.
